SWAGGER (API docs) - what to type
=================================
Endpoints:
  GET  /ping     - is the API up
  GET  /health   - model loaded, champion model, thresholds
  POST /score    - score one transaction

How: click the endpoint > "Try it out" > paste a body > "Execute".
GET /health needs no body: Try it out > Execute.

IMPORTANT: change "event_id" and "card_token" every time you send
(add -2, -3 ...). The bodies use a fixed event time, so they give
the same decision at any hour.

1) ALLOW - USD 25 grocery, 2 km from usual location   (score about 0.06)
{
  "event_id": "swagger-a-1",
  "customer_id": "7919",
  "card_token": "swagger-a-1",
  "amount": 25.0,
  "merchant_name": "W-MERCHANT-gmail.com",
  "mcc": "5411",
  "merchant_country": "US",
  "geo_distance_km": 2.0,
  "event_timestamp_ms": 1793943900000
}

2) REVIEW - USD 899 electronics, Russia, 8,742 km away   (score about 0.12)
{
  "event_id": "swagger-b-1",
  "customer_id": "7919",
  "card_token": "swagger-b-1",
  "amount": 899.0,
  "merchant_name": "C-MERCHANT-hotmail.com",
  "mcc": "5732",
  "merchant_country": "RU",
  "geo_distance_km": 8742.0,
  "event_timestamp_ms": 1793943900000
}

3) BLOCK - USD 1,500 electronics, 3,000 km away   (score about 0.28)
{
  "event_id": "swagger-c-1",
  "customer_id": "7919",
  "card_token": "swagger-c-1",
  "amount": 1500.0,
  "merchant_name": "W-MERCHANT-gmail.com",
  "mcc": "5732",
  "merchant_country": "US",
  "geo_distance_km": 3000.0,
  "event_timestamp_ms": 1793943900000
}

Response fields to point at:
  decision             ALLOW / REVIEW / BLOCK
  fraud_score          the XGBoost probability
  scoring_latency_ms   time inside the API, in milliseconds
  velocity_hit         true if the card-testing rule fired
  blocklist_hit        true if the card / IP / device is blocklisted
  feature_completeness share of the 43 model features available on this event

Optional velocity trick (only if time allows):
  Send body 1 five times within one minute with the SAME card_token
  but a NEW event_id each time (swagger-a-1, swagger-a-2, ...).
  The 5th one comes back REVIEW with velocity_hit = true.
